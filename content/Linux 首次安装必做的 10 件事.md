新部署 Ubuntu/Debian 系统后的最佳优化步骤与避坑指南。

## 1. 优化镜像源
在软件更新器中将软件源切换为阿里云（Aliyun）镜像源，大幅提升软件更新与 `apt` 安装速度。

## 2. 配置输入法框架
确保安装 `fcitx` 输入法框架后安装中文输入法。

## 3. 安装 gdebi 包管理器
默认的图形软件管理器安装 `*.deb` 包时经常遇到依赖冲突，`gdebi` 可以自动解决依赖：

```bash
sudo apt-get install gdebi
```
