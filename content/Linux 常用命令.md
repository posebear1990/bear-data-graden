Linux 系统管理与日常 Shell 命令备忘。

## Shell 逻辑运算符

* `&&`：逻辑与 (AND) 运算符。只有前一条命令成功返回 0 时，才继续执行后面的命令。
* `&`：后台工作。置于完整指令列最末端，将该任务放入后台执行。

## SSH 密钥配置

```bash
# 生成 2048 位 RSA 公钥与私钥
ssh-keygen -t rsa

# 将 id_rsa.pub 公钥无缝分发部署至远程服务器 ~/.ssh/authorized_keys
ssh-copy-id -i ~/.ssh/id_rsa.pub root@123.456.789.123
```

## 磁盘空间与文件容量分析

```bash
# 查看目前所有已挂载文件系统的可用空间及使用百分比
df -h

# 递归深度为 1 查验特定目录下各个子文件夹占用的真实磁盘空间
du -h --max-depth=1 /var/log
```
