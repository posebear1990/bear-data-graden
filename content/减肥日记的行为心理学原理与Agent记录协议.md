# 减肥日记的行为心理学原理与Agent记录协议

> **背景**：基于与 Gemini 的深度讨论整理（[原始对话链接](https://gemini.google.com/app/b6567953baefda78)）。将传统枯燥的卡路里记账升级为**「人类随性写日常流水账 + AI Agent 自动拆解营养/能耗/代谢盲点并同步 Notion」**的闭环系统。

---

## 1. 写减肥日记为什么能减肥？（行为与认知干预原理）

大量临床与行为心理学研究（如美国凯撒医疗机构 Kaiser Permanente 的长期大规模减重实验）显示：**保持记录饮食习惯的人，减重幅度往往是不记录者的两倍左右**。日记本身不消耗卡路里，其核心在于通过心理与认知干预改变行为习惯：

### 1.1 打破「无意识进食」，消除隐形热量
* **认知失调纠偏**：人在回忆饮食时，大脑倾向于低估摄入量（平均低估 20%–50%）。路过随手抓的一把坚果、尝的一口甜点、奶茶里的糖浆，常被自动忽略。
* **显性化呈现**：一旦需要落笔或录入软件，这些“隐形热量”全部被迫曝光，建立起真实的每日热量全景。

### 1.2 行为经济学中的「摩擦力」与「观察者效应」
* **增加决策摩擦**：记录创造了一个心理门槛——每次伸手拿零食前，会下意识预判：“吃了就得记下来，这口饼干值得我专门记一笔吗？”这种犹豫往往足以切断冲动进食（参见 [[环境设计与自控力-如何构建支持良好习惯的环境]]）。
* **霍桑效应（自我监控）**：当一个人意识到自己的行为正在被观察（即便观察者是自己）时，会不自觉地规范自身行为，更倾向于选择健康、低负担的食物。

### 1.3 闭环反馈：从「感觉」到「数据复盘」
* **定位平台期与体重新高根源**：体重出现波动或停滞时，主观猜测往往会带来焦虑甚至极端节食。日记提供了可追溯的数据：是否连续几天钠超标导致水肿？或是周末聚餐热量超标？
* **建立精准奖惩反馈**：看到清晰的规律（如“蛋白质吃够的那几天下午没有暴食渴望”），能极大强化健康选择的正向反馈。

### 1.4 识别「情绪性进食」诱因
* **情绪与饥饿解绑**：很多人发胖并非源于生理饥饿，而是压力、无聊或熬夜后的情绪代偿（参见 [[抗压心理学与压力管理指南]]）。
* **认知溯源**：记录时若顺带标明用餐场景与情绪状态（例如：“深夜加班焦虑，点炸鸡”），能在认知层面上看清诱因，逐步寻找替代压力的健康手段，而非靠食物填补心理空缺。

### 1.5 可持续记录的三大核心法则

| 核心法则 | 具体做法 | 避坑提醒 |
| :--- | :--- | :--- |
| **实时记，别拖到睡前** | 饭前拍照或吃完立即记录，记忆最准确。 | 拖到睡前容易遗漏酱料、饮料等关键细节。 |
| **抓大放小，追求可持续** | 估算核心分量与三大营养素（碳水、蛋白质、脂肪），或只拍图打卡。 | 切忌苛求精确到 0.1 克的极端称重，极易引发疲惫与弃坑。 |
| **记录情绪与诱因** | 暴食或加餐时，标注触发场景（如熬夜、焦虑）。 | 严禁在日记里进行自我攻击或产生负罪感；日记是客观记录仪，不是道德审判法庭。 |

## 2. 专属 Agent System Prompt 与 Notion 同步协议

日常只需向 Agent 发送一段白话随笔，Agent 将自动执行以下提取规则，并同步写入 Notion 的 **📓 2026** 数据库（Data Source ID: `36953ff5-7504-4e82-a619-7211affc57c5`）。

### 2.1 核心提取与换算规则
1. **食材与计量默认规则**：
   * 记录的主食米/杂粮，**未特别声明时一律默认按【生重】计算**（生米 85g $\approx$ 180–200g 熟饭 $\approx$ 300 kcal）。
   * 估算常见食材热量与三大营养素（碳水 C、蛋白质 P、脂肪 F），加工食品（如香肠、火腿）需额外关注**钠含量**与脂肪比例（高钠易引起次日水分潴留/水肿）。
   * 常备优质蛋白替代方案（参见 [[健康饮食与哑铃全身燃脂训练计划]]）：即食鸡胸肉、冷冻虾仁、免切牛肉片、嫩豆腐、鸡蛋。
2. **运动消耗折算**：
   * 严格区分“在场/总时长”与“核心有效运动时间”。
   * 仅对有效运动时段计算能耗，间歇练习或休息时间按轻微活动估算，避免高估热量赤字产生“可以随便大吃”的代偿错觉。
3. **作息与激素观察**：
   * 追踪睡眠时间与昼夜节律。白天过长补觉或凌晨晚睡会导致皮质醇升高、瘦素分泌下降（参见 [[皮质醇调控与精力管理-斯坦福神经生物学指南]]），引发水肿及次日对高碳水/高盐食物的强烈渴望。
4. **保留原始随笔**：
   * 完整保留用户的原始生活随笔，绝不破坏记录生活琐事的乐趣。
