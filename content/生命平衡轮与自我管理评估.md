# 生命平衡轮与自我管理评估

生命平衡轮是用于定期自查生活状态、平衡精力分配与降低无谓内耗的评估框架。

## 1. 评估维度与打分规则

采取 **3 分制自查标准**：
* **3 分**：达成预定目标。
* **2 分**：有实质行动或对现状基本满意。
* **1 分**：现状很不满意，存在明显内耗或焦虑。

| 评估维度 | 核心目标与理想状态 | 常见误区与调适策略 |
| :--- | :--- | :--- |
| **健康 (Health)** | 身体健康与心理安定，保持精力充沛。 | 避免因焦虑而暴饮暴食或熬夜，建立规律作息。 |
| **工作 (Work)** | 保持专业兴趣与技能竞争力，按时完成 KPI。 | **不把工作作为自我实现的唯一目标**，避免将工作压力转化为破坏健康的消极拖延。 |
| **财富 (Wealth)** | 稳健的资产配置与长期理财。 | 关闭实时行情与频繁盯盘，避免让碎片化的市场波动干扰主业。 |
| **自我实现 (Growth)** | 拥有属于自己的独立作品（如软件/工具/文章）。 | 小步启动，避免停留在脑海规划而迟迟不开始。 |
| **娱乐 (Leisure)** | 获得能够真正滋养身心、深度放松的长效娱乐。 | 警惕低质短视频等无意识的“奶头乐”刺激带来的事后空虚与时间焦虑。 |
| **环境 (Environment)** | 保持居家与个人环境的基本整洁与舒适。 | 不必过于苛求完美，维持不产生环境焦虑的基准线即可。 |

## 2. 核心调适心法

1. **分离工作与自我价值**：工作是生活的一部分，保持专业度与性价比，但不盲目把自我认同全盘绑定在单一职务上。
2. **长效放松 vs 廉价刺激**：通过阅读、户外运动、艺术体验等进行高质量深度放松。
3. **消除拖延与焦虑循环**：焦虑通常源于“没有开始”，通过切分极小任务单元打断“拖延-内耗-更拖延”的恶性循环。
